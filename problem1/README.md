# Problem 1: Container Networking

This directory contains the implementation of Linux Network Namespaces topology, ping utility script, and conceptual explanations for routed/tunneled networking scenarios.

## Files
- 'setup_topology.sh': Shell script to construct Figure 1 network namespace topology.
- 'ping_node.sh': Helper script to ping a target node or router from a source node.
- 'figure2_explanation.md': Conceptual response and routing analysis for Figure2.
- 'figure3_explanation.md': Conseptual response and routing analysis for Figure3.
